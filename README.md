# MiniBanking

MiniBanking is a faculty project that demonstrates a distributed banking system built with Java 21, Spring Boot and Spring Cloud.

The repository is being implemented incrementally. Every service and cross-cutting capability is introduced through a focused, buildable commit.

## Planned modules

- Infrastructure: Eureka Discovery Server, Spring Cloud Config Server and API Gateway.
- Business services: Customer, Account, Transaction, Card and Notification.
- Composition service: Banking Overview with OpenFeign, Resilience4j and load balancing.
- Platform: Keycloak, RabbitMQ, Docker Compose, Zipkin, Prometheus and Grafana.

Detailed startup instructions, ports, API examples and the defense guide will be added after the executable system is complete.
